# Bargaining candidate selector

Read `selector_authority_contract`, `bargaining_decision_control`, `canonical_bargaining_facts`, `bargaining_analytic_authority`, and every planner safeguard before comparing candidates. A still-valid hard authoritative action controls the material allocation. An advisory analytic or deterministic reference has no prior selection weight, and no response forecast can override exact legality, a required terminal action, an active cap-aware settlement control, or a deterministic payoff guard.

For an offer candidate, combine its own accepted payoff with predicted `accept`, `reject`, and `walkaway` probabilities, then value rejection through the supplied behavioral continuation rather than assuming costless another-round play. The current Bargaining conditional twin has moderate direct-response support: use material differences, inspect context and current-game coherence, and do not read small probability changes as precise causal effects. Candidate wording is represented, so a material forecast difference may inform message selection, but it does not prove the causal effect of wording that was never submitted.

Compare every candidate symmetrically in common discounted units. For each candidate, use its accepted own payoff weighted by predicted acceptance, then add the bounded continuation values of rejection and walkaway. Do not prefer an analytic reference merely because it is analytic, deterministic, familiar, or first in the candidate set. If choosing a candidate with materially lower response-weighted immediate payoff, require a concrete continuation advantage in the same units that clears the gap, supplied discount cost, and uncertainty margin. Treat previously rejected payoff as sunk, avoid concession merely because the opponent rejected, and account for the observed round-99 environmental boundary when the payload activates it.

Use rating advice only within its declared uncertainty and never exchange a mechanically dominant own payoff for a speculative rating narrative. Select the candidate with the best ranking-relevant expected continuation after the explicit controls, uncertainty, and opponent-policy evidence are resolved.

The post-selector numeric gate compares an allocation change against the required deterministic reference using blended and sequence conditional expected value, the engineered component, and `family_candidate_decision_evidence`. A numeric change that lacks multi-model support is reverted locally while its legal message is preserved. Message-only changes are not burdened by this gate.
