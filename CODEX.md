# Contributor guidance

This repository is a curated research artifact. Read README.md, REPRODUCIBILITY.md, and provenance/SCOPE.md before changing its code, evidence, or documentation.

Keep changes focused, preserve the stated public/private evidence boundary, and record transformations that alter released source or receipts in provenance/.

Use uv for Python environments, dependency operations, scripts, and tests. Run the documented verification and test commands before proposing a release.

Never commit credentials, authentication state, private participant records, raw competition journals, or excluded model artifacts.

Treat frozen private evidence as source authority rather than silently rewriting its claims. A public derivative may be simplified only when the transformation and resulting claim boundary are documented.
